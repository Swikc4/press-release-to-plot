# Press Release to Plot Industry Comparison

Academic team project completed for CIS 3120 Programming for Analytics at Baruch College in Spring 2026.

## My Role

I was the **Financial Services Pipeline Lead** for Team 11. My teammates were Imran Aslam, Travel and Hospitality Pipeline Lead, and Gabriel Asimakopoulos, Comparison and Visualization Lead and Integrator.

## Project Overview

Our team compared location related business events in the Financial Services and Travel and Hospitality industries. The workflow used SEC EDGAR filings, Python, REST API requests, an LLM based classification step, geocoding, pandas, and Folium.

For the Financial Services side, I worked with the industry ticker list and search phrases and helped test the pipeline across different time windows. The project showed how expanding search terminology could substantially improve event discovery.
